1GitHub bağlantısı

Ayarlar ve günlük baskılar GitHub deposunda () tutulur. Bu sayfanın değişiklik yapabilmesi için bir kez GitHub anahtarı girin; anahtar yalnızca bu cihazda saklanır. Uygulamayı kullananların hiçbir şey girmesi gerekmez.

  1. Yeni GitHub anahtarı sayfasını açın. Token name: haber-masasi-yonetim, Expiration: 1 yıl.
  2. Repository access → Only select repositories → haber-masasi.
  3. Permissions → Repository permissions: Contents, Actions ve Secrets için Read and write seçin.
  4. Generate token deyin, çıkan github_pat_… metnini aşağıya yapıştırın.
Aşağıdaki bölümler kilitli. Bu tarayıcı GitHub'a bağlı değil. Bağlantı her tarayıcıda ayrı tutulur; başka bir tarayıcıda bağlandıysanız burada da bir kez 1. adımda GitHub anahtarını yapıştırıp Bağlan deyin.

2Gemini anahtarı bilinmiyor

Haberleri her sabah özetleyen Google Gemini'nin anahtarı. Ücretsizdir, kart istemez. Anahtar GitHub'a şifrelenerek kaydedilir; bu sayfada bile bir daha görünmez.

  1. aistudio.google.com/app/apikey adresinde Google hesabınızla giriş yapın.
  2. Create API key deyin, anahtarı kopyalayıp aşağıya yapıştırın.

4Ülkeler ve kaynaklar

Kullanıcılar burada eklediğiniz ülkelerden istediklerini seçer. Her ülke için haberlerin derleneceği RSS adreslerini girin (haber sitesinin "RSS" bağlantısı). Gemini her ülke için bu kaynaklardan 5-10 önemli haber seçer.

5Kaydet ve yayınla

Ayarları kaydedin. Bugünün baskısı henüz yoksa hemen hazırlanır; varsa yeni ayarlar yarın sabahtan geçerli olur. Hemen yeni bir baskı için Şimdi hazırla'ya basın (birkaç dakika sürer).
